Why it asks for your own API key. This is a static page with no server behind it. A shared key would sit in the JavaScript where anyone could read it and spend it. So it uses yours, in your tab — never stored, never sent anywhere except straight to Anthropic. Press tile a demo canon to try the renderer with no key at all.

To make it keyless for visitors, deploy worker/worker.js — a Cloudflare Worker holding the key as a secret behind rate limiting and a spend cap — and set CC_STUDIO_ENDPOINT to its URL. That is the only change required.
